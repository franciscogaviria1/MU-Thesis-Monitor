# MU Thesis Monitor

## Mission

Build a local-first decision-support dashboard that helps evaluate whether the Micron Technology (MU) investment thesis is strengthening or weakening.

This project is a thesis-monitoring system.

This project is NOT:
- a stock prediction tool
- a trading bot
- an automated investment advisor
- a buy/sell signal generator

## Core Principles

1. Reliability over complexity.
2. Evidence over opinion.
3. Explainability over prediction.
4. Deterministic rules over AI judgment.
5. Human and AI can both be wrong.
6. Token efficiency is a first-class requirement.
7. Incremental improvements over rewrites.

## AI Rules

AI may:
- classify headlines
- summarize evidence
- explain score changes
- identify contradictions
- generate bull and bear cases

AI must not:
- invent facts
- invent sources
- create market data
- calculate final thesis scores
- issue trading instructions
